# MatchaScript

Matcha Auto-Pray Script for Roblox.

## Quick Loadstring

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/kysrn-ww/MatchaScript/main/auto_pray.lua"))()
```

## Features

- Auto-prays continuously (presses **B** key every 0.5s).
- Press **T** to toggle active state ON/OFF.
- Native Matcha notifications on screen.
